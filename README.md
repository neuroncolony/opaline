# Opaline

A calm, self-custodial marketplace for tokenized real-world assets: stocks, ETFs, gold, treasuries and private credit from every major issuer, priced live and routed across 20+ chains.

- Markets, asset pages with charts, issuer spreads, issuers, liquidity pools
- Baskets (build, backtest, share, buy in sequence), curated strategies
- Yield and lending explorers with calculators
- Swap from any token on any chain (LI.FI routing), zero added fees
- Limit orders, auto-invest and price alerts with browser notifications
- Built-in agent with plain-language commands, optional own OpenAI key
- Portfolio tracking for any EVM address

Run: `python3 server.py` (stdlib only). Env: `PORT`, `DATA_DIR` (mount a volume), optional `OPALINE_CG_KEY`, `LIFI_API_KEY`.
